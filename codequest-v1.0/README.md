# CodeQuest
Learn to code by playing. Made by Vasireddy Saran Manikanta.

48 story levels across HTML, CSS, JavaScript, Python, SQL and Machine Learning. XP, badges, a personal roadmap, guest or email login, memes (Telugu for Andhra Pradesh and Telangana, English for others) and a helper called Quest Buddy.

## Run locally
Open index.html in a browser (or use the Live Server extension in VS Code).

## Notes
- Accounts and progress are stored in the player's own browser (localStorage). There is no server.
- Google sign-in is optional: paste a Google client ID into GOOGLE_CLIENT_ID in auth.js.
- Edit memes in memes.js.
